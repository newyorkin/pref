# Правила работы с newyorkin/pref

- Перед новой задачей обновляй сведения об удалённых ветках и проверяй основную ветку репозитория. Сейчас это `master`. Создавай отдельную рабочую ветку от актуальной `origin/master`; направляй PR в `master`.
- Выполняй задачи по `.claude/commands/implement-ticket.md`. Для последовательности задач также используй `.claude/commands/next-tickets.md`. Эти инструкции применяются к любым агентам и рабочим средам; указанные инструменты предпочтительны, а допустимые замены описаны в самих инструкциях.
- После подготовки каждого PR автоматически запускай отдельного агента для независимого ревью. Передавай ему задачу, актуальный diff и материалы проверок; предпочитай свежий контекст без выводов автора изменений. Следуй процедуре ревью из `implement-ticket.md`, исправляй подтверждённые замечания и сообщай результат. При существенных изменениях после ревью проводи повторное независимое ревью.
- Предпочитай Claude Opus для ревью, если он доступен; иначе используй другого доступного независимого агента. Если запуск агента невозможен, явно укажи причину и оставь PR открытым до независимого ревью другим агентом или человеком. Самопроверка не заменяет независимое ревью.
- Сливай PR только при разрешении пользователя, после успешных обязательных проверок и независимого ревью, без нерешённых блокирующих замечаний. Слияние в `master` автоматически запускает выкладку на https://pref-test.yorkin.online. При проверке выкладки сверяй версию справа снизу с хешем коммита сборки.
