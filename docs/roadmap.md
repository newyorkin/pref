# Следующие функции: оценка и порядок

Это план для отдельного согласования. Новые функции из P3 в изменения безопасности и устойчивости не включены. Оценки относительные: S — небольшая задача, M — несколько связанных сценариев, L — отдельный этап разработки с продуктовым согласованием.

| Возможность | Текущее состояние | Объём | Следующий шаг |
| --- | --- | --- | --- |
| Ссылка-приглашение | Уже реализована: создание стола возвращает `/table/:id`, ссылка доступна в лобби | S для улучшений | Проверить вход по ссылке с телефона, копирование и заполненный стол; не создавать второй механизм приглашений |
| История и разбор сдач | Есть записи сдач, последний расклад и экспорт; снимки стола теперь переживают перезапуск | M | Согласовать отдельную историю завершённых сдач и формат сохранения всех раскладов; открывать карты только после завершения соответствующей сдачи. Связано с issue #10 |
| Мобильная вёрстка | Есть адаптивные стили, но нет систематической проверки всех размеров | M–L | Сначала согласовать поддерживаемые размеры и ориентации; проверить торговлю, снос, взятку, диалоги и пулю. Часть замечаний уже описана в issues #6–21 |
| Таймер хода и AFK | Нет согласованной политики таймаута | M–L | Решить длительность, паузу при потере связи и результат истечения. Хранить срок в SQLite, проверять на сервере; команды таймера должны учитывать версию и оставаться идемпотентными после рестарта |
| Боты | Нет реализации | L | Сначала согласовать замену игрока и возврат человека, затем простой легальный бот и отдельная стратегия. Бот должен видеть только разрешённое представление своего места; часы и случайность остаются на сервере |
| Чат за столом | Нет реализации | M | Согласовать срок хранения и правила сообщений; добавить ограничение длины/частоты, серверное связывание автора с сессией и восстановление истории без передачи закрытых карт |
| Статистика и рейтинг | Есть пользователи и результаты внутри стола, но нет отдельного рейтингового журнала | L | Сначала добавить постоянный реестр завершённых партий, затем согласовать формулу рейтинга, неполные игры и защиту от повторного начисления |
| Звуки | Нет реализации | S–M | Определить события, настройку выключения и поведение в фоне; проверить мобильный браузер и отсутствие повторных звуков после переподключения |

Предлагаемый порядок: проверить имеющиеся приглашения → история и разбор → мобильный интерфейс → таймер/AFK → боты → чат → рейтинг. Звуки можно согласовать отдельно как небольшое улучшение.

До реализации таймера и ботов необходимо согласовать, могут ли автоматические действия менять результат игры и какие именно действия допустимы при отсутствии человека. В текущем PR таких изменений правил нет.
